# Politique de sécurité

La politique complète, le modèle de menace et les limites connues sont dans
[docs/SECURITY.md](docs/SECURITY.md).

Pour signaler une vulnérabilité, n’ouvrez pas d’issue publique : utilisez un
avis de sécurité privé GitHub lorsque le dépôt est publié, ou contactez
directement les mainteneurs. Indiquez la version, la plateforme, les étapes de
reproduction et l’impact estimé. Ne joignez jamais un vrai coffre ni un vrai mot
de passe.

Coffre n’a pas encore fait l’objet d’un audit externe. Les builds de
distribution macOS doivent être signés avec un certificat Developer ID et
notariés ; voir [docs/AUDIT-2026-11-07.md](docs/AUDIT-2026-11-07.md).
